# 3.2 Оценка информационной плотности датасета (common crawl)

**Результат оценки информационной плотности**:
Итоговая информационная плотность датасета составила 2.800 нат/токен (nats per token).
Оценка производилась методом взвешенного среднего: суммарный Negative Log-Likelihood (NLL) всех объектов был разделен на суммарное количество токенов в датасете (17.5 млн токенов). Это гарантирует, что длинные документы вносят пропорционально больший вклад в общую метрику, чем короткие.

**Интерпретация метрики**
 битах: $2.80/ln(2) = 4.04 бит/токен$.
 Перплексия (Perplexity): $e^{2.80} = 16.4$. Это означает, что в среднем для предсказания следующего токена GPT-2 «выбирает» из примерно 16 наиболее вероятных вариантов. Для сырого/слабо очищенного веб-корпуса (Common Crawl) это адекватный показатель, говорящий о том, что текст обладает естественной языковой структурой.
